# Trinity Web Synth

A browser synthesizer inspired by the Korg Trinity V3 with the MOSS board. It opens Trinity (and Triton) `.PCG` program files and plays their programs and combinations with its own sound engine.

**Try it:** https://moss-synth.netlify.app (Chrome or Edge recommended)

> **Work in progress.** This is a hobby project, and most of the code was written with AI assistance. Expect bugs, missing features and sounds that differ from the real instrument. Don't expect it to always work as intended.

## Features

- **MOSS programs**: 13 oscillator models (Standard, Comb, VPM, Resonance, Ring, Cross, Sync, Organ, E.Piano, Brass, Reed, Plucked, Bowed), filters, envelopes, LFOs and modulation.
- **PCM programs**: Single and Double mode with their own filters, envelopes and LFOs. Multisamples are played by openly licensed General MIDI recordings or built-in waveforms, so they sound only roughly like the original.
- **Combinations**: 8 timbres with key and velocity zones, mixing, insert effect chains and master effects.
- **Effects**: insert and master effects, EQ.
- **Playing**: on-screen keyboard, joystick, ribbon, Web MIDI, Arabic maqam scales, a full-screen play mode for phones, and a MIDI mode for external keyboards.
- **Programs**: browser with search, favourites and recently played; new programs; saving to a User bank.
- **Extras**: WAV recording, and install as an app that also works offline.
- **Not supported**: drum kits, the Solo-TRI board (Bank S).

A few starter programs are included. No sound banks come with the synth: use **Import Trinity PCG** to load your own files. For example, Korg's free [EXB-MOSS bank](https://www.korg.com/us/support/download/software/1/270/3183/) (`MOSS_EXT.PCG`).

## Run locally

```
python3 build.py              # builds index.html from the sources
python3 -m http.server 8765   # then open http://localhost:8765/index.html
```

The page must be served over http, because audio, MIDI and the samples need it.

## Development

- Sources: `engine.js` (MOSS), `pcm.js` (PCM), `combi.js`, `fxdsp.js` / `fxcat.js` (effects), `korg.js` (PCG reader), `patches.js`, `app/` (UI), `ui.html` (template). `build.py` joins them into `index.html`, so don't edit `index.html` directly.
- `npm install` once, then `npm run lint`. Run `sh test/run_all.sh` for the tests (needs Node 18+, python3 and ffmpeg; the browser test also needs Playwright). The tests use made-up test banks generated by `test/fixtures.js`, so they need no PCG files.
- If you want banks built into your own copy of the page, put them in `private/`. Git ignores that folder, so they are never committed.
- `CLAUDE.md` has detailed notes on the code, the data formats and the conventions. `docs/research/` has notes on the file formats.
- `tools/samples/build_packs.py` rebuilds `samples/` from the MS General SoundFont.
