KORG TRINITY - COMBINATION PARAMETER STRUCTURE  (388 bytes)
===========================================================

Source: Trinity Parameter Guide, MIDI Implementation "[TABLE 3] COMBINATION PARAMETERS", dated 8.Dec.1995
(Trinity V1), scanned page 188 of KorgTrinity-ParameterGuideWithMIDIImplementation.pdf
(github.com/dave-billin/Toluene/doc/).  Page image: research/scans/p188_table3_combination.png
(The TR-Rack text calls this TABLE2 but does not contain it; only the scan has it.)
Cross-checked with PCG Tools (TrinityTimbres.cs: timbres at offset 236, 8 x 19 bytes) and with the user's
PCG files (section type 2): timbre program/bank refs resolve to sensible programs, key/vel zones, MIDI ch
0x10 = GLOBAL, etc.

PARA No. = Parameter ID , SUB ID (hex) for PARAMETER CHANGE;  n = timbre number 0..7 (T1..T8).

LISTS
  PROGRAM BANK (237): 00 Bank A, 01 B, 02 C (extended/Flash only), 03 D (extended only), 04 S (Solo)
     PCG Tools (TrinityProgramBanks.GetBankWithPcgId) maps 4 -> S bank if loaded, else M bank (Trinity V3).
  KEY SLOPE (250): 0:0, 1:1 semitone, 2:2, 3:3, 4:4, 5:6 (0.5 oct), 6:8, 7:10, 8:12 (1 oct), 9:18 (1.5 oct),
     10(A):24 (2 oct), 11(B):30 (2.5 oct), 12(C):36 (3 oct), 13(D):48 (4 oct), 14(E):60 (5 oct), 15(F):72 (6 oct)
  VEL SLOPE (253): 0:0, 1:8, ... F:120   (velocity fade slope = value x 8)
  INSERT EFFECT SIZE (254): 0 OFF, 1 Size 1, 2 Size 2, 3 Size 4, 4..B = Timbre 1..8
     (4..B presumably "use the insert effect chain of timbre N")
  PAN (244): 00..7F = L00..R127, 80 = PROG, FF = OFF
  DELAY START (243): see program list (00..60 time steps, FF = key off)

NOTES
  * TIMBRE MODE: combi table (V1) lists 0 INT, 1 OFF, 2 EXT; the SONG table (TABLE 8, same track layout)
    lists "0..3 : INT, OFF, EXT, BOTH". PCG Tools (TrinityTimbre.cs) instead decodes bits 6..5 as
    {Int, Off, Both, Ext} -- conflicting for values 2/3; Korg's order (2 = EXT, 3 = BOTH) is more likely.
    In the user's files only 0 (INT) and 1 (OFF) occur.
  * The combination's bytes 20..235 (8 insert FX groups + master FX) have the same layout as the SONG table's,
    which Korg documents in detail -- see 06_effects.txt.
  * PCG Tools field map for the timbre (offsets relative to timbre start, all consistent with the table):
    +0 program no., +1 bank, +2 b0-4 MIDI ch, +2 b5-6 status, +3 volume, +4 bend range (signed),
    +5 transpose (signed), +11 b6 force poly, +11 b5 hide OSC2, +12 key top, +13 key bottom,
    +15 vel top, +16 vel bottom.
  * PCG Tools' TrinityCombi.cs puts "Tempo" at offset 541 -- a copy/paste from Triton; not valid for Trinity.
  * TABLE 5 (Combination PLAY-mode parameter numbers, not stored): TIMBRE BANK 00..04 (A..S) 00,00+4n;
    TIMBRE PROGRAM 00..7F 00,01+4n; TIMBRE PANPOT 00..7F (L00..R127) 00,02+4n; TIMBRE VOLUME 00..7F 00,03+4n.
