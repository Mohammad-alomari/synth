KORG TRINITY - PCM ("ACCESS") PROGRAM PARAMETER STRUCTURE  (433 bytes)
=======================================================================

Sources (both Korg; they agree byte-for-byte except where noted):
  [TRI] Trinity Parameter Guide, MIDI Implementation, "[TABLE 1] PROGRAM PARAMETERS (for PCM Synth)",
        dated 29.Aug.1995 (Trinity V1). Scanned pages 181-183 of
        KorgTrinity-ParameterGuideWithMIDIImplementation.pdf (github.com/dave-billin/Toluene/doc/).
        Page images: research/scans/p181_table1_prog_0-80.png, p182_table1_prog_81-432.png, p183_table1_prog_notes.png
  [TRR] TR-Rack MIDI Implementation (1997.09.29 / 1997.12.25), Korg text file TR_RACK_MIDIimp.txt,
        https://www.korg.com/us/support/download/manual/1/212/2728/  (verbatim copy: research/src_TR-Rack_MIDI-implementation_pdftotext.txt)
        TR-Rack = rack version of Trinity, identical 433-byte program format.

Differences TRI vs TRR:  byte 16 b4-7 (TRI: CATEGORY B; TRR: reserved), byte 21 (TRI: panel SW1/SW2 assign;
TRR: reserved), multisample range (TRI: 000-176h = 0-374; TRR: 000-19Eh = 0-414, TR-Rack has 40 more).

VERIFIED against the user's PCG files (program section type 0): names, osc mode, multisample numbers
(= correct instruments, e.g. Clarinet=104, Violin=152, A.Piano=0), EG/level ranges, effect sizes.

Conventions
  No.      : byte offset inside the 433-byte program record (PCG record == SysEx dump after 7->8 bit unpack).
  b0..3    : bit field (b0 = LSB).
  Signed   : values shown as "9D..63 : -99..99" are 8-bit two's complement (0x9D = -99).
  16-bit   : MSB byte first (big-endian).  Multisample number = ((b[31]&0x7F)<<8) | b[32]  (8-bit LSB!,
             verified: LSB values > 0x7F occur, e.g. 0x00A4 = 164).
  PARA No. : Parameter ID , SUB ID (hex) for SysEx PARAMETER CHANGE (F0 42 3g 3B 41 ...). For OSC-1 block
             rows "a/b": a = OSC1 sub ID, b = OSC2 sub ID (OSC2 param ID = OSC1 ID + 2 for IDs 02,03,07,08,0B,0C,0F,10).
  $        : ignored when Oscillator Mode = Drum.      # : ignored in Combination / Song (Sequencer) / Multi.

ENUMERATION LISTS (footnotes; TRI numbering differs from TRR by +1 after *5 because TRI inserts the SW list)
---------------------------------------------------------------------------------------------------------
SCALE TYPE (19 b4-7): 0 Equal Temperament, 1 Pure Major, 2 Pure Minor, 3 Arabic, 4 Pythagoras,
  5 Werckmeister, 6 Kirnberger, 7 Slendro, 8 Pelog, 9 1-Octave User Scale (RAM), 10 Stretch,
  11 All-Range User Scale (RAM)            (range given as 0..C)
RANDOM INTENSITY (20), random pitch range in semitones: 0: 0, 1: +-1/64, 2: +-1/32, 3: +-1/16, 4: +-1/8,
  5: +-1/4, 6: +-1/2, 7: +-1
SW ASSIGN (21; also combination byte 19)      value : function (MIDI out)
  0 J.S(X) Lock (P.Bend hold)   1 J.S(+Y) Lock (CC#01 hold)   2 J.S(-Y) Lock (CC#02 hold)
  3 Ribbon Cont(X) Lock (CC#16 hold)   4 Ribbon Cont(Z) Lock (CC#17 hold)   5 A.T Lock (A.Touch hold)
  6 JS & Ribbon Lock (each control lock)   7 Octave Down (note no. -1 oct)   8 Octave Up (+1 oct)
  9 Portamento Off (CC#65 off/on)   10 Modulation CC#80 (SW1) / CC#81 (SW2)
  (range in table is 0..8; 9,10 listed in the note)
AMS - ALTERNATE MODULATION SOURCE (range 00..16h = 0..22; 23..26 only from OSC2)
  0 OFF  1 OSC EG  2 Filter EG (same OSC)  3 Amp EG (same OSC)  4 OSC LFO (same OSC)  5 Filter LFO (same OSC)
  6 Velocity  7 Note No.  8 Poly After  9 After Touch  10 Joystick X (Pitch Bend)  11 Joystick +Y (CC#01)
  12 Joystick -Y (CC#02)  13 Ribbon X (CC#16)  14 Ribbon Z (CC#17)  15 Assignable Pedal (CC#04)
  16 Value Slider (CC#18)  17 MIDI CC#19  18 Assignable Panel SW1 (CC#80)  19 Assignable Panel SW2 (CC#81)
  20 Assignable Pedal SW (CC#82)  21 MIDI CC#83  22 Tempo (MIDI clock count)
  23 Filter 1 EG  24 Amp 1 EG  25 OSC 1 LFO  26 Filter 1 LFO   (23-26 only selectable in OSC2)
MULTISAMPLE: lower/higher multisample is chosen by velocity (BOTTOM VEL OF HI MS).
  Observed in PCG data (not in doc): value 0x1000|n (MSB byte 0x10) appears for many user programs;
  most likely = RAM/Flash (PBS-TRI sample option) multisample n. Treat 0x0000-0x0176 as ROM.
DELAY START (41): 00..19h: 0..50 ms (2 ms step); 1A..28h: 60..200 ms (10 ms); 29..38h: 250..1000 ms (50 ms);
  39..60h: 1100..5000 ms (100 ms); FF: start at NOTE OFF
PITCH SLOPE (42): F6 = -1.0 (-12 semitones/oct), 00 = 0.0 (flat), 0A = +1.0 (normal), 14 = +2.0 (24 st/oct)
  -> value = signed byte / 10.
PITCH INT "-12.00..12.00" (43,44,50,53,66), signed byte:
  8D..C3 : -12.00 .. -1.20  (0.20 step)      C4..CD : -1.00 .. -0.55 (0.05 step)
  CE..32 : -0.50 .. +0.50  (0.01 step)       33..3C : +0.55 .. +1.00 (0.05 step)
  3D..73 : +1.20 .. +12.00 (0.20 step)
J.S(X) INTENSITY (46,47): C4 = -60 (-5 oct), 00 = off, 0C = +12 (+1 oct)  (semitones)
STEP (48): 0 continuous, 1 = 1/8 semitone, 2 = 1/4, 3 = 1/2, 4 = 1, ... F = 12
LFO WAVE (54, 92): 0 Triangle 0deg, 1 Tri 90, 2 Tri 180, 3 Tri 270, 4 Saw Up 0, 5 Saw Up 180, 6 Saw Down 0,
  7 Saw Down 180, 8 Rectangle 0, 9 Rect 180, 10 Sine 0, 11 Sine 180, 12 Guitar,
  13 Random1 (time fixed, level random), 14 Random2 (time random, level fixed), 15 Random3 (both random),
  16 Random4 (=13 with ramp), 17 Random5 (=14 with ramp), 18 Random6 (=15 with ramp)
LFO START MODE: ON = start at note-on (normal); OFF = start at note-off; BOTH = start at note-on, stop at note-off
LFO FADE: <0 fade out (ON mode at note-on / OFF mode at note-off / BOTH: out at on, in at off);
          >0 fade in (normal)
FILTER TYPE: 0 Low Pass, 1 High Pass, 2 Band Pass, 3 Band Reject
FILTER ROUTING: 0 Parallel, 1 Serial, 2 Single, 3 Through
KEYBOARD TRACK (figured): between LOW KEY and HIGH KEY a straight line; below LOW / above HIGH a ramp set by
  LOWER/HIGHER RAMP.
PAN (163): when panned by A.M it acts around its initial setting.  FF = OFF (no output to L/R bus).

TABLE 5/6 of TRI (Program Play mode "performance edit" params, PARA 00,00..00,07; not stored in memory):
  OCTAVE FD..03 (-3..+3), CUTOFF F6..0A (-10..+10), FILTER EG INT, AMP LEVEL, ATTACK TIME, RELEASE TIME,
  INSERT FX BALANCE, MASTER FX BALANCE (all F6..0A).
